# Historical documentation archive

This directory freezes legacy documentation that was removed from the active docs surface during the first slice of `flagship-documentation-overhaul`.

## Why this exists

- Reduce noise in `docs/` by separating frozen legacy material from the active documentation surface.
- Preserve historical context without presenting old material as current operational truth.
- Keep previously committed artifacts available for audits, portfolio traceability, and rollback research.

## Archived files

| File | Reason for archive |
| --- | --- |
| `docs/archive/README.md` | Previous Spanish documentation index replaced by the current English IA index at `docs/README.md`. |
| `docs/archive/exploration-report.md` | Research artifact kept for traceability, not day-to-day repo navigation. |
| `docs/archive/MANUAL_USUARIO.md` | Legacy user manual superseded by the active architecture/runbook surface and upcoming guides. |
| `docs/archive/MANUAL_INSTALACION.md` | Historical deployment guide that will be replaced by a current English deployment guide. |
| `docs/archive/INFORME_TECNICO_SPRINT_3.md` | Point-in-time sprint report, preserved as historical context only. |
| `docs/archive/ESTRUCTURA_PROYECTO.md` | Legacy project map that no longer reflects the canonical docs structure. |

## How to use this archive

- Treat every file here as a frozen snapshot.
- Expect stale placeholders, outdated instructions, and Spanish-only content.
- Do not use archive files as the primary source of truth for current operations.
