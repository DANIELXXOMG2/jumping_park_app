# Logo usage recommendations

## Practical rules

- usar el nombre `Jumping Park` como marca principal
- priorizar fondos con contraste alto y suficiente aire alrededor del logo
- no deformar, rotar ni aplicar glow excesivo
- si no hay logo final vectorial versionado, usar wordmark simple antes que improvisar un isotipo dudoso

## Portfolio context

- el logo acompana, no reemplaza la evidencia de producto
- en capturas del admin o kiosk, evitar que la marca tape KPIs o CTAs
- mantener consistencia entre README, pagina publica y portfolio captions
