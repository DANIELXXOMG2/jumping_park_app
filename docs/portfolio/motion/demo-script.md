# Short demo script

Objetivo: un demo de 45-75 segundos, usable como GIF corto o video narrado.

## Sequence

1. Abrir `consentimiento-digital` y mostrar la historia publica del producto.
2. Pasar al kiosk: ingreso -> OTP -> consentimiento.
3. Mostrar el caso offline o mencionar el replay seguro con una toma real si esta disponible.
4. Cambiar al admin: dashboard con freshness, lista cursor-first, detalle de consentimiento.
5. Cerrar con `robots.txt` o `llms.txt` como evidencia de polish tecnico.

## Narrativa sugerida

- problema: filas, papel y poca trazabilidad
- solucion: kiosk digital con OTP, firma y soporte a menores
- hardening: accesibilidad, offline-safe replay, costos controlados en admin
- cierre: superficie publica lista para SEO y AI-SEO

## Capture notes

- cursor visible solo cuando aporte contexto
- transiciones cortas, sin zooms bruscos
- si usas voz, mantener 120-150 palabras maximo
